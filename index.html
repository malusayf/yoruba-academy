Learning notes

Yoruba is a tonal language. Tone marks and letters such as ẹ, ọ and ṣ are meaningful. Browser speech synthesis may not include a Yoruba voice; playback is disabled when none is available, rather than mispronouncing words with an English voice.

Vocabulary is an introductory sample, not a comprehensive dictionary. Always verify specialized or regional expressions with a fluent speaker.

Install the companion Chrome extension from the extension folder using chrome://extensions → Developer mode → Load unpacked.
